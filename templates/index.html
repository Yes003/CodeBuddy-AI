About CodeBuddy AI

A personal coding mentor engineered to bridge the gap between getting stuck and building genuine programming intuition using Google's Gemma 4.

The Beginner Problem

Beginner programmers frequently get stuck on cryptic error messages, subtle logical bugs, and intimidating syntax. Existing AI assistants often dump raw code without explaining the underlying reasoning, creating dependency rather than true comprehension.

The Gemma 4 Solution

CodeBuddy AI uses Google's Gemma 4 (26B-A4B-IT) to act like an encouraging, patient senior teaching assistant. It explains code logic through everyday metaphors, points out tricky edge cases, and maintains conversation context so students can ask follow-ups.

Technology Stack

  • AI Core: Google GenAI SDK (google-genai>=2.0.0) with Gemma 4 (gemma-4-26b-a4b-it)
  • Fallback AI: OpenAI / OpenRouter SDK (openai>=1.12.0)
  • Backend: Python 3.11+, Flask 3.x, Flask-CORS
  • Frontend: HTML5, CSS3 Custom Properties, Vanilla JS (ES6+), Prism.js
  • Environment: Python-dotenv for secure local credential isolation
  • Testing: Pytest automated suite covering all modes and chat routes

Security & Safety Guarantees

  • Zero Arbitrary Execution: The server never executes or compiles user-submitted code (no eval()).
  • No Client-Side Secrets: API keys are kept strictly in backend .env and never exposed in frontend scripts.
  • Strict Prompt Guardrails: User code is treated strictly as passive data to prevent prompt injection.
  • Quota & Rate-Limit Resilience: Automatically catches HTTP 429 quota errors and provides smooth fallback.
